# Marca Leo Castro Personal

## Símbolo
Um **C** laranja aberto para a direita com um **L** cuja base atravessa a abertura: as iniciais de
Leo Castro e a ideia de movimento e evolução, saindo do lugar.

## Cores
| Cor | Código | Uso |
|---|---|---|
| Azul-marinho | `#0f2742` | Cor principal: textos do logo, fundos, topo do app |
| Laranja | `#ff6b1a` | Destaque: o "C" do símbolo, detalhes, botões no modo escuro |
| Branco | `#ffffff` | Logo sobre fundos escuros |

Evite texto pequeno laranja sobre fundo branco (pouco contraste). Prefira o azul-marinho.

## Fonte
**Inter Display** (Black no nome, SemiBold em "PERSONAL TRAINER"). É gratuita (licença SIL Open Font):
https://rsms.me/inter/ — nos arquivos SVG o texto já está convertido em desenho, então não precisa
ter a fonte instalada para usar o logo.

## Arquivos
| Arquivo | Quando usar |
|---|---|
| `leo-castro-horizontal` (.svg / .png) | Fundo claro: site, assinatura de e-mail, documentos |
| `leo-castro-horizontal-negativo` | Fundo escuro ou foto escura |
| `leo-castro-vertical` / `-negativo` | Espaços quadrados ou verticais (camiseta, cartaz) |
| `leo-castro-simbolo` / `-negativo` | Só o símbolo: marca d'água em vídeos, carimbo, detalhe |
| `leo-castro-icone-app.png` | Ícone do app |
| `leo-castro-perfil-instagram.png` | Foto de perfil do Instagram e WhatsApp (1080×1080) |

Use **SVG** para impressão (gráfica, adesivo, camiseta): amplia sem perder qualidade.
Use **PNG** para redes sociais e mensagens.

Para alterar o desenho: `gerar-logo.py` gera todos os SVGs (precisa de Python com `fonttools` e `uharfbuzz`).
